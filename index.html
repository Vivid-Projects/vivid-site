Our standard

Measures you can read

Every number in your report comes from a named, documented measure. When someone asks "how is growth calculated?", the answer is one line away.

Revenue YoY % =
VAR CurrentYear = [Total Revenue]
VAR PriorYear =
    CALCULATE ( [Total Revenue], SAMEPERIODLASTYEAR ( 'Date'[Date] ) )
RETURN
    DIVIDE ( CurrentYear - PriorYear, PriorYear )
// DIVIDE returns blank instead of an error when last year is empty
